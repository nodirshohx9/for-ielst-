# IELTS Academy

IELTS Academic Band 7.0 uchun o‘zbek tilidagi interaktiv tayyorlov platformasi. Telefon va kompyuterda ishlaydi.

## Ishga tushirish

Node.js o‘rnating va terminalda:

```bash
npm install
npm run dev
```

Brauzerda http://localhost:5173 ni oching.

## Vercel

GitHub repository’ni Vercel’da Import qiling. Framework: Vite. Build Command: `npm run build`. Output Directory: `dist`.

## Imkoniyatlar

- Grammar, Vocabulary, Reading testlari va o‘zbekcha tushuntirishlar
- Listening ovozli o‘qish (brauzer qo‘llab-quvvatlasa)
- Writing va Speaking mashqlari
- Natijalarni brauzer localStorage xotirasida saqlash

AI avtomatik baholash va qurilmalararo sinxronlash hozircha mavjud emas.
